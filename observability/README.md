# Observabilité CityFlow

Ce dossier regroupe les ressources de supervision prêtes à intégrer :

- `prometheus/cityflow-alerts.yml` : règles d’alerte;
- `grafana/dashboards/cityflow-diffusion.json` : tableau de bord;
- `grafana/provisioning/` : provisionnement de la source Prometheus et du tableau de bord.

Le guide d’exploitation complet se trouve dans `docs/operations/observability.md`.
