# Candidat de version 1.0

## Portée figée

Le candidat regroupe uniquement les fonctions validées de diffusion, isolation municipale, supervision, sauvegarde, reprise et exploitation.

## Barrières

- tests automatisés au vert;
- aucune vulnérabilité critique connue non acceptée formellement;
- migrations testées sur une copie représentative;
- sauvegarde et restauration réussies;
- test de capacité conforme;
- alertes et tableaux de bord fonctionnels;
- documentation administrateur, exploitation et soutien disponible;
- décision GO documentée.

## Période d’observation

Aucun changement fonctionnel n’entre dans le candidat. Seules les corrections bloquantes, de sécurité ou de documentation sont admises, chacune avec preuve et retour arrière.
