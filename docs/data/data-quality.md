# Qualité des données CityFlow

## Dimensions

- exactitude;
- complétude;
- fraîcheur;
- cohérence;
- unicité;
- traçabilité.

## Contrôles

Chaque donnée utilisée pour une diffusion ou un rapport possède une source, une date, un responsable et des règles de validation. Les anomalies ne sont jamais corrigées silencieusement en production.

## Isolation

Les contrôles sont exécutés dans le périmètre municipal approprié. Aucun rapport de qualité ne doit révéler les données d’une autre municipalité.

## Suivi

Toute anomalie importante reçoit une gravité, un propriétaire, une correction et une preuve de résolution.
