# C13 — Checklist de gestion des données

## Statut

**CHECKLIST DISPONIBLE — AUCUN JEU DE DONNÉES APPROUVÉ**

## Objet

Encadrer l’acquisition, l’utilisation, la transformation, le partage, la conservation et la suppression des données CityFlow.

## Critères d’entrée

- [ ] la finalité et la base d’autorisation sont documentées;
- [ ] la source, le propriétaire et le responsable opérationnel sont identifiés;
- [ ] les catégories de données et les personnes concernées sont connues;
- [ ] la classification et les obligations applicables sont établies;
- [ ] les consommateurs et territoires autorisés sont recensés.

## Contrôles

- [ ] seules les données nécessaires sont collectées;
- [ ] la provenance, la licence et les restrictions sont vérifiées;
- [ ] le schéma, les unités et les règles de qualité sont versionnés;
- [ ] les transformations sont reproductibles et traçables;
- [ ] les accès suivent le moindre privilège;
- [ ] le chiffrement, les sauvegardes et la restauration sont adaptés;
- [ ] la durée de conservation et le sort final sont définis;
- [ ] les partages et transferts sont autorisés et journalisés;
- [ ] les mécanismes de correction et de suppression sont testés;
- [ ] les données de test ne reproduisent pas inutilement des données sensibles.

## Validation et sortie

- [ ] la qualité est mesurée sur un échantillon représentatif;
- [ ] les limites, biais et données manquantes sont documentés;
- [ ] T6, T9, T14 et T19 sont mis à jour;
- [ ] les preuves d’autorisation, qualité et suppression sont conservées;
- [ ] les incidents et écarts ont un responsable et une échéance;
- [ ] la prochaine revue est planifiée.

## Verdict

- verdict : `AUTORISÉ / AUTORISÉ AVEC RÉSERVES / REFUSÉ / INCONCLUSIF`;
- portée :
- autorité :
- date :
- preuves :
- réserves :

## Barrière finale

Le respect de cette checklist ne prouve pas que les données sont exactes, complètes ou légalement utilisables dans toute situation. Chaque usage demeure limité à sa finalité, sa version, son territoire et ses preuves.
