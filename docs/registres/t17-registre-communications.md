# T17 — Registre des communications

## Statut

**REGISTRE INITIALISÉ — AUCUNE COMMUNICATION RÉELLE CONSIGNÉE**

## Objet

Conserver les communications importantes de CityFlow, leur public, leur contenu, leur validation, leur diffusion, leurs corrections et leurs preuves.

## Champs minimaux

| Champ | Description |
|---|---|
| Identifiant | Référence stable |
| Sujet | Objet compréhensible |
| Type | Avis, changement, incident, interruption, décision ou autre |
| Public | Destinataires visés |
| Responsable | Personne chargée du message |
| Validateur | Autorité ayant approuvé le contenu |
| Canal | Courriel, portail, site, réunion, média ou autre |
| Contenu | Message ou lien vers sa version conservée |
| Impacts | Conséquences et alternatives communiquées |
| Incertitudes | Limites, inconnues et réserves |
| Date prévue | Moment planifié de diffusion |
| Date réelle | Moment effectif de diffusion |
| Preuve | Trace de publication ou réception |
| Correction | Mise à jour, retrait ou rectification liée |
| État | Préparée, validée, diffusée, corrigée ou retirée |

## Cycle de vie

1. Identifier le besoin, le public et le responsable.
2. Préparer un message clair avec impacts, alternatives et limites.
3. Valider contenu, accessibilité et autorité.
4. Diffuser par les canaux convenus.
5. Conserver la preuve de diffusion et les réactions utiles.
6. Corriger rapidement toute information erronée ou dépassée.
7. Archiver les versions sans effacer l’historique.

## Gouvernance

- propriétaire du registre : responsables des communications CityFlow;
- mise à jour : à chaque préparation, diffusion, correction ou retrait;
- revue : avant diffusion sensible et après incident significatif;
- rapprochement : avec parties prenantes, incidents, changements et publications;
- historique : messages, validations, preuves et corrections conservés.

## Preuves attendues

- version validée du message;
- identité du validateur;
- preuve de diffusion;
- liste ou définition du public;
- corrections et avis de remplacement;
- retours nécessitant une action.

## Barrière finale

Une communication inscrite n’est pas présumée reçue, comprise, accessible ou exacte dans le temps. Chaque qualité exige une preuve adaptée au public et au canal.
