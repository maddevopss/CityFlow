# T18 — Registre des publications

## Statut

**REGISTRE INITIALISÉ — AUCUNE PUBLICATION RÉELLE CONSIGNÉE**

## Objet

Conserver les contenus officiellement publiés par CityFlow, leur source, leur version, leur autorité, leur portée, leur diffusion, leurs corrections et leur retrait.

## Champs minimaux

| Champ | Description |
|---|---|
| Identifiant | Référence stable |
| Titre | Désignation publique |
| Type | Donnée, avis, rapport, document, flux ou autre |
| Source | Origine autorisée du contenu |
| Autorité | Responsable ayant autorisé la publication |
| Version | Version exacte publiée |
| Territoire | Portée géographique ou organisationnelle |
| Public | Destinataires ou consommateurs |
| Canal | Site, portail, API, fichier, média ou autre |
| Date prévue | Moment planifié |
| Date réelle | Moment effectif |
| Validations | Contrôles exécutés avant publication |
| Preuve | URL, empreinte, capture ou journal |
| Correction | Publication de remplacement ou rectification |
| Retrait | Date, raison et preuve de retrait |
| État | Préparée, publiée, corrigée, remplacée ou retirée |

## Cycle de vie

1. Identifier source, autorité, portée et public.
2. Fixer la version et les validations requises.
3. Autoriser explicitement la publication.
4. Publier par un canal traçable.
5. Vérifier disponibilité, contenu et fraîcheur.
6. Corriger ou remplacer sans effacer l’historique.
7. Retirer avec justification et preuve lorsque nécessaire.

## Gouvernance

- propriétaire du registre : responsables de publication CityFlow;
- mise à jour : à chaque préparation, publication, correction, remplacement ou retrait;
- revue : avant toute publication externe et après anomalie;
- rapprochement : avec communications, versions, données, validations et métriques;
- historique : versions, autorisations, preuves et retraits conservés.

## Preuves attendues

- source et version publiées;
- autorisation datée;
- résultats des validations;
- preuve de diffusion;
- contrôle de fraîcheur;
- correction ou retrait traçable.

## Barrière finale

Une publication inscrite n’est pas présumée actuelle, exacte, complète, reçue ou juridiquement autorisée. Chaque qualité doit être démontrée pour une version, une portée et une période précises.
