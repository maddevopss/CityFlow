# Contrôles de qualité des données P2

## Objet

Définir les contrôles obligatoires avant qu’un jeu de données puisse soutenir une preuve P2.

## Dimensions contrôlées

- complétude;
- exactitude vérifiable;
- cohérence interne;
- unicité;
- fraîcheur;
- représentativité;
- traçabilité de provenance.

## Procédure

Chaque contrôle produit une mesure, un seuil, un résultat, un écart et une décision. Les corrections doivent être versionnées et rejouables.

## Règle de blocage

Un jeu présentant un défaut critique, une provenance incertaine ou un taux d’erreur non mesuré est rejeté.
