# Données du portefeuille 1.x

## Objet

Ce document encadre les données requises, produites ou transformées par les initiatives CityFlow.

## Fiche de données

Chaque initiative identifie les catégories de données, la finalité, la source, le responsable, les accès, la durée de conservation, les transferts et la méthode de retrait.

## Principes

Les données sont minimisées, exactes, accessibles seulement selon le besoin et séparées entre organisations lorsque requis.

## Qualité

Les décisions fondées sur les données déclarent leur fraîcheur, leur couverture, leurs erreurs connues et les transformations appliquées.

## Cycle de vie

La création, l’usage, la copie, l’exportation, l’archivage et la suppression sont traçables.

## Interdictions

Une nouvelle finalité, un nouveau partage ou une conservation prolongée exige une décision explicite.

## Règle finale

Une donnée disponible n’est pas automatiquement une donnée autorisée, fiable ou nécessaire.
