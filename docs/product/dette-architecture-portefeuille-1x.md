# Dette d’architecture du portefeuille 1.x

## Objet

Ce document encadre les choix structurels qui limitent l’évolution, la fiabilité ou l’isolation de CityFlow.

## Registre

Chaque dette décrit la décision d’origine, les contraintes actuelles, les composants touchés, les risques, les dépendances, les options et le coût d’inaction.

## Déclencheurs

Une revue est obligatoire lorsqu’une dette :

- bloque plusieurs initiatives;
- fragilise l’isolation ou l’intégrité;
- impose des contournements répétés;
- augmente fortement les coûts d’exploitation;
- empêche un retrait ou une migration.

## Décision

La dette est acceptée temporairement, réduite, remplacée ou éliminée avec un propriétaire et une échéance.

## Règle finale

Une architecture qui exige toujours plus d’exceptions n’est pas stable : elle reporte ses décisions sur les équipes suivantes.
