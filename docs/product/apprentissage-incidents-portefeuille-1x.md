# Apprentissage après incident du portefeuille 1.x

## Objet

Ce document transforme les incidents liés aux initiatives CityFlow en corrections durables du portefeuille.

## Analyse

L’analyse distingue le déclencheur, les conditions contributives, les contrôles absents ou inefficaces, les impacts, la détection et le rétablissement.

## Portée

Les enseignements peuvent modifier une initiative, une barrière, une priorité, une dépendance, une pratique d’exploitation ou une règle de gouvernance.

## Actions

Chaque action possède un responsable, une échéance, une preuve attendue et une condition de fermeture. Les actions temporaires sont distinguées des corrections structurelles.

## Culture

L’analyse recherche les mécanismes et décisions, non un coupable commode. Les responsabilités restent néanmoins explicites.

## Règle finale

Un incident déclaré clos sans changement vérifié demeure un incident susceptible de se répéter.
